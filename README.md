# sql-complete-mastery-project


## Overview
This project is a structured SQL learning journey designed to take me from beginner to advanced level in SQL.

It covers all major SQL concepts using a business-style dataset including customers, orders, products, and sales data.

---

## Project Goals
- Master SQL fundamentals
- Learn data aggregation and analysis
- Understand table relationships using JOINs
- Practice advanced SQL techniques such as subqueries and window functions
- Learn how to structure real-world SQL projects

---

## Project Structure

01_basic_sql/
02_aggregation/
03_joins/
04_subqueries/
05_window_functions/
06_stored_procedures/
07_case_study/

---

## Dataset Description

The project uses a simulated retail business database:

- Customers: customer information and location
- Orders: purchase transactions
- Order Details: products inside each order
- Products: product catalog with price and cost
- Payments: transaction payment details
